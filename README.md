Windows 桌面办公工具，包含报价转换、Word 服务清单、收支表、询价函、方案解构、网络拓扑、设备图库及抠图模型等功能。

## 运行方法

1. 下载 `digital-office-v1.0.0-windows-x64.zip`。
2. 将整个 ZIP 解压到本机文件夹。
3. 打开解压后的 `解决方案-产数小微ICT工具箱` 文件夹，双击 `解决方案-产数小微ICT工具箱.exe`。

请保留 EXE 同目录中的 `_internal` 文件夹。本次发布为完整 ZIP，可直接解压运行；旧版 `Setup.exe` 不适用于本次发布包。

程序包来自 2026-09-28 构建的现有 dist，共包含 5,316 个程序及资源文件，版本继续使用 v1.0.0。
